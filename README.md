## 🚀 Featured Project

### 🍔 Ordery — Food Delivery App

A full-stack food delivery application inspired by Talabat & Elmenus, with a Flutter frontend and a Node.js backend.

**✨ Highlights**
- 🔐 Email & Google Authentication
- 🍽 Browse restaurants & category-based menus
- 🔍 Smart search & ❤️ favorites
- 🛒 Cart & 💳 custom checkout flow with payment selection
- 📍 Interactive map picker
- 🔔 Firebase push notifications
- 📦 Real-time order tracking via Socket.io
- 💾 Offline caching with Hive
- ☁️ Cloudinary-powered image pipeline on the backend

**🛠 Tech Stack**
`Flutter` `Dart` `BLoC` `Clean Architecture` `Dio` `Hive` `Firebase` `Socket.io` `GetIt` `Injectable` `GoRouter`
`Node.js` `Express` `MongoDB` `Mongoose` `Cloudinary`

👉 **Repo:** [github.com/Abdalla-Ahmed-Aly/Ordery](https://github.com/Abdalla-Ahmed-Aly/Ordery)
